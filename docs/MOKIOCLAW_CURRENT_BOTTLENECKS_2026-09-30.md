# MokioClaw 当前瓶颈（2026-09-30）

## 当前状态

阶段 B 的本地实施分支已同步到本地 `main`。任务工作台、隔离副本、受控工具与诊断已有实现；Task 10 的真实修复仍未完成。最新一次授权试点 `6QKRh-o6P2mrL8yQBLNSIW7B` 以 `failed / task_tool_failed` 结束，公开摘要为 `FileEditTool / tool_rejected`。它只在隔离任务副本留下 2 文件、+32/-0 的部分补丁，Agent 固定验证为 `not_run`。该轮授权额度已用尽，不能据此宣称 Grep 或 Bash 缺陷已经修复。

## 主要瓶颈与证据

1. **补丁尚未达到安全边界。** 最新部分补丁用路径字符串前缀判断文件是否位于根目录。固定镜像内的无 provider 临时夹具已证明：链接可指向名称有共同前缀的兄弟目录，并读出范围外内容。检查与打开之间的替换竞态也没有处理。另存的 `docs/task10_grep_symlink_candidate.patch` 只验证了跳过文件符号链接这一局部思路，未证明目录链接、并发替换或 Windows junction／reparse point 等边界安全；它不是可直接应用的最终修复。
2. **真实试点仍无法形成完整验证闭环。** 最新任务在编辑工具拒绝后停止，固定验证 `not_run`。独立在隔离副本运行相同 pytest 命令得到 42 passed、2 deselected，但那不是 Agent 执行的固定验证，且上述越界探针仍失败。此前 30000 token 上限的两轮也没有形成可用实现。下一次试点必须先有可审查的完整边界方案和无 provider 回归，再另行授权真实运行。
3. **模型阶段消耗高，而失败细节受到脱敏边界限制。** 30000 token 上限的两轮分别报告 41428 与 41834 token；现有事件与预算检查支持它们由累计已报告 token 达限停止，精确的 provider 接受或计费请求数不可恢复。上限提高到 80000 后，最新任务记录入口 1／577、规划 2／3941、CodeAgent 6／63752，合计 9 次已启动调用／68270 已报告 token；它并未触及本轮 token 或 16 次调用上限，而是因工具拒绝停止。受控公开摘要没有失败路径或编辑片段，因此不能推定 `tool_rejected` 的具体原因，也不能把高消耗归因于某个 Grep／Bash 缺陷。
4. **工作台交互有间歇性失效。** 曾出现页面预览不显示结果、启动确认超时；本机 API 在核对任务身份和运行清单后可继续操作。超时后必须先只读确认任务是否已经创建或启动，以免重复运行。页面交互的根因仍未定位。
5. **平台验证仍有缺口。** 本次同步后的指定 Windows Python 非 Docker 全项目回归为 756 passed、3 skipped、35 deselected；3 项跳过与本机符号链接创建权限有关，35 项 Docker 用例不在该结果内。Linux 容器里的独立探针揭示了越界问题；Windows 特有链接类型和竞态仍需专门验证。

## 下一步顺序

1. 在隔离副本中针对普通文件、文件和目录链接、兄弟目录同名前缀、并发替换与 Windows 链接类型写可失败的无 provider 安全测试，确定路径约束与打开文件的原子边界。
2. 用假模型复现编辑工具拒绝和预算阶段消耗，检查任务提示、工具调用和编辑匹配的交互；只保留固定类别及数值计数，不暴露源码片段、路径或 provider 秘密。
3. 形成完整补丁后运行固定验证和安全探针，再考虑新的真实试点授权。正式 Rich／Click 冻结证据、试点来源仓库和远端保持原状。
